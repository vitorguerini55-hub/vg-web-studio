# VG Web Studio

Site institucional estático da VG Web Studio, com a direção visual aprovada por Vitor.

## Estrutura
- `index.html`: conteúdo, navegação, clientes e briefing.
- `styles.css`: identidade visual, responsividade e movimento reduzido.
- `app.js`: serviços, filtros, demonstrações e briefing local.
- `assets/`: assinaturas vetoriais da marca.
- `vercel.json`, `robots.txt`, `sitemap.xml`: publicação, segurança e indexação.

## Publicação
Framework: Other (estático). Sem instalação ou build. Diretório de saída: `.`. Produção: https://vg-web-studio.vercel.app/ . Após conectar este repositório à Vercel, usar `main` como branch de produção.

## Escopo preservado
Foco em sites, alimentação, cardápios, catálogos, encomendas e painéis. Cliente: Nosso Pão, com link para o site. Demonstrações identificadas; nenhuma venda real nos exemplos.

## Contato
O briefing funciona localmente: o visitante pode copiar ou baixar o resumo. Nenhuma solicitação é enviada. O número de WhatsApp comercial da VG ainda precisa ser fornecido pelo responsável antes de acrescentar envio direto.

## Verificação
Validar `node --check app.js`, navegação, filtros, abas de alimentação/catálogo/painel, briefing, redução de movimento e layout mobile/desktop. Não há backend ou chaves neste projeto.
